THE SCIENCE, IN THE OPEN

Two forecasts. Different questions.

The overview answers “what weather is expected?” The laboratory asks “how does a simple numerical temperature model behave?”

01 / Live weather

Open-Meteo combines numerical weather prediction models to provide current conditions and hourly and daily forecasts. This app displays those predictions with their location, model time and data source.

Read the forecast documentation ↗

02 / An interpretable model

The laboratory evolves temperature from thermal relaxation, the previous day’s profile and a daylight heating term. It corrects the original notebook’s RK4 initialization, intermediate-stage evaluation, time units and calendar handling.

Parameters are fitted on an earlier day. The following day is held out for comparison with historical model values. The persistence baseline repeats the previous day at the same hour.

03 / What the scores mean

MAE measures average absolute temperature error. RMSE gives larger errors more weight. Skill is measured relative to 24-hour persistence. A negative skill score means the numerical model was worse on that reference day.

The experiment is small, uses model-derived reference data, and is not a validated weather forecasting service.

04 / Built to be explored

Everything runs in your browser. No accounts or API keys. Saved Oxford data is clearly marked with its acquisition date and can be explored when the live service is unavailable.
